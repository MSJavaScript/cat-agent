# Tips for working efficiently

NEVER use `cat` to get the content of a structure or files generated by softwares (e.g. *.cif, *.extxyz, POSCAR, OUTCAR, etc.), they contain large amount text which is meaningless to you. Use `grep`, `sed` etc to get a chunk of content or use python packages such as `ase` and `pymatgen` to get meaningful informations.

## Security issues
- Be cautious when deleting files or directories. 
- Avoid installing any programs or libraries to avoid pollution, ask the user to install them manually.
- For long python or bash scripts, write them into a file and add necessary comments to facilitate inspection, do not execute them directly in the command line. 

## Efficiently read and edit files by bash commands

Bash are more efficiently than python for simple reading and editing tasks. 

To append some lines to a file:
```bash
echo XXX >> file
echo YYY >> file
```

To get the content of some keywords:
```bash
grep PATTERN file
```

To print from line `a` to line `b` of a file:
```bash
sed -n "<a>, <b> p" file
```

To replace the content from line `a` to line `b` with some texts
```bash
sed -i '<a>,<b>c Today\nIs\nFriday' file
```

To delete lines with keywords "aa" and "bb" in a file
```bash
sed -i "/aa\|bb/d" file
```

To quickly get the last 3 lines of vasp.stdout in opt_* dirs:
```bash
tail -n 3 opt_*/vasp.stdout
```

By flexibly utilizing these commands, `sed`, `grep`, `awk`, `cut`, `echo` and so on. The text searching and editing will be very efficient.

## Use Python or awk for numerical calculations

Use python or awk for numerical calculations, for example

```bash
awk 'BEGIN{print 10-3}' # 7
awk 'BEGIN{print exp(1)}'  # 2.71828
awk 'BEGIN{srand(); print rand()}' # get random number
echo $RANDOM # get a random integer
# Formatted output
awk 'BEGIN{printf "%.2f\n", 10/3}'  # 3.33
awk 'BEGIN{printf "%d\n", 10/3}'    # 3
# Simple integer operation 
i=1
let i=i+1  # 2
i=$((i+3)) # 5
```

Use python for complex calculations
```bash
python3 -c "print('hello')"
python3 -c "print(sum(range(10)))"

python3 << 'EOF'
import numpy as np
import matplotlib.pyplot as plt
x = np.linspace(0, 10, 100)
plt.plot(x, np.sin(x**2))
plt.savefig("plot.jpg", dpi=150)
EOF
```
